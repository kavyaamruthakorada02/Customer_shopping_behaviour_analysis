Customer Shopping Behavior Analysis
Overview
This project analyzes customer shopping behavior using Python, SQL Server, and Power BI. The workflow covers data loading, exploratory data analysis (EDA), data cleaning, feature engineering, SQL-based business analysis, dashboard development, and presentation of insights.
The project is designed to demonstrate practical data analytics skills from raw data to business insights.
Dataset
- Dataset: Customer Shopping Behavior
- Records: 3,900 customer transactions
- Key fields: Age, Gender, Item Purchased, Category, Purchase Amount, Location, Season, Review Rating, Subscription Status, Shipping Type, Discount Applied, Previous Purchases, Payment Method, and Frequency of Purchases.
Tools & Technologies
- Python — data loading, EDA, cleaning, and feature engineering
- Pandas — data manipulation and analysis
- SQL Server — business queries and analytical SQL
- Power BI — interactive dashboard and visualization
- Gamma — project presentation / PPT
- SQLAlchemy + pyodbc — Python-to-SQL Server connection

1. Data Loading & EDA
The dataset is loaded into Pandas and reviewed using:
- head() for sample records
- info() for data types and structure
- describe() for descriptive statistics
- isnull().sum() for missing-value analysis
The Python workflow is documented in Customer_Behaviour_Analysis.py.
2. Data Cleaning & Feature Engineering
The project includes the following transformations:
- Missing Review Rating values are filled using the median rating within each product category.
- Column names are converted to lowercase and spaces are replaced with underscores.
- purchase_amount_(usd) is renamed to purchase_amount.
- An age_group feature is created using age quartiles.
- Purchase frequencies are converted into numeric day values using purchase_frequency_days.
- promo_code_used is removed after checking that it contains the same Yes/No information as discount_applied.
The cleaned dataset can then be loaded into SQL Server for further analysis.
3. SQL Server Analysis
The cleaned customer data is loaded into a SQL Server database named customer_behaviour_analysis, into the customer table.
The SQL analysis covers business questions such as:
1. Revenue generated by male vs. female customers
2. Customers who used discounts but spent at least the average purchase amount
3. Products with the highest average review ratings
4. Average purchase amount for Standard vs. Express shipping
5. Spending and revenue comparison between subscribers and non-subscribers
6. Products with the highest percentage of discounted purchases
7. Customer segmentation into New, Returning, and Loyal customers
8. Top 3 products within each category
9. Subscription status among customers with more than 5 previous purchases
10. Revenue contribution by age group
The SQL queries are available in customer_shopping_behavior_analysis.sql.

How to Run
Step 1 — Install Python dependencies
pip install pandas sqlalchemy pyodbc
Step 2 — Place the dataset
Keep the CSV file in the same working directory as the Python script:
customer_shopping_behavior.csv
Step 3 — Run the Python analysis
python Customer_Behaviour_Analysis.py
The script performs EDA, cleaning, feature engineering, and loads the processed data into SQL Server.
Step 4 — Configure SQL Server
The current Python script uses:
- SQL Server / SQL Express
- Database: customer_behaviour_analysis
- Table: customer
- Windows Trusted Connection
- ODBC Driver 17 for SQL Server
Update the connection settings in the Python file if your SQL Server instance is different.
Step 5 — Run SQL analysis
Open:
customer_shopping_behavior_analysis.sql
in SQL Server Management Studio (SSMS) and execute the queries.
Step 6 — Open the Power BI dashboard
Open:
Customer_Behaviour_Analysis.pbix
Refresh the data source if required and explore the dashboard.
